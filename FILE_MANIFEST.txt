NAVIGATION STRUCTURE:
====================

index-new.html (HOME)
  ├─→ About.html (About link in nav)
  ├─→ products.html (Shop links)
  └─→ Featured/Popular cards → product-detail.html?id={productId}

about.html (ABOUT)
  ├─→ index-new.html (Home link)
  ├─→ products.html (Shop/Browse links)
  └─→ commission CTA → products.html

products.html (SHOP)
  ├─→ index-new.html (Home link in nav)
  ├─→ about.html (About link in nav)
  ├─→ Product card click → product-detail.html?id={productId}
  └─→ Filters/Search/Sort all products

product-detail.html (PRODUCT)
  ├─→ index-new.html (Home link in nav)
  ├─→ about.html (About link in nav)
  ├─→ products.html (Back to Shop / Shop link in nav)
  ├─→ Related products → product-detail.html?id={productId}
  └─→ Display full product info with images

HOW TO USE:
===========

1. Start with: index-new.html
2. Navigate using top navigation menu
3. Browse products on products.html
4. Click products to see details
5. Use filters and search on products page
6. Use local server for best experience:
   python -m http.server 8000
   Then visit: http://localhost:8000


CUSTOMIZATION TIPS:
===================

1. Add New Product:
   - Edit js/products-data.js
   - Add product to products array
   - Automatically appears everywhere!

2. Change Colors:
   - Edit css/common.css
   - Update CSS variables in :root

3. Update Content:
   - Edit HTML files directly
   - All content is in the files

4. Add More Pages:
   - Follow the same pattern
   - Import css/common.css
   - Use same navigation structure
